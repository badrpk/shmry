# 🚀 SHMRY Admin Dashboard - Smart Storage Management

## 📋 Overview
The SHMRY Admin Dashboard provides a beautiful, modern web interface for managing your Smart Storage Management System. Monitor storage, control downloads, manage admin devices, and perform emergency operations - all from an intuitive dashboard.

## 🎯 **Quick Access Methods**

### **1. Desktop Shortcut (Recommended)**
```bash
# Run the PowerShell script to create desktop shortcuts
.\create-desktop-shortcut.ps1

# Or use the batch file
.\create-desktop-shortcut.bat
```

### **2. Direct Launch**
```bash
# Simple launcher
.\launch-admin-dashboard.bat

# Or open directly in browser
start admin-dashboard.html
```

### **3. File Path Access**
```
D:\shmry-edge-computing\admin-dashboard.html
```

## 🖥️ **Dashboard Features**

### **📊 Real-Time Status Cards**
- **💾 Storage Status** - Visual storage usage with color-coded warnings
- **📥 Active Downloads** - Current download count and progress
- **✅ Completed Models** - Total successfully downloaded models
- **🌐 Admin Devices** - Online admin device count

### **🔧 System Controls**
- **🔄 Refresh Status** - Update dashboard data
- **🚨 Emergency Cleanup** - Force storage cleanup and model relocation

### **📊 Storage Management**
- **💾 Check Storage Health** - Comprehensive storage diagnostics
- **⚡ Optimize Storage** - Automatic storage optimization
- **📋 View System Logs** - Access detailed system logs
- **📊 Export Report** - Generate system status reports

### **🔍 Monitoring Tools**
- **🌐 Test Admin Devices** - Verify admin device connectivity
- **📊 System Activity** - Real-time system activity logs
- **📦 Model Overview** - Complete AI model inventory with locations

## 🚀 **How to Create Desktop Shortcuts**

### **Option 1: PowerShell Script (Recommended)**
1. **Right-click** on `create-desktop-shortcut.ps1`
2. **Select** "Run with PowerShell"
3. **Follow** the prompts
4. **Shortcuts** will be created on your desktop

### **Option 2: Batch File**
1. **Double-click** `create-desktop-shortcut.bat`
2. **Follow** the prompts
3. **Shortcuts** will be created on your desktop

### **Option 3: Manual Creation**
1. **Right-click** on desktop → New → Shortcut
2. **Target**: `"C:\Program Files\Internet Explorer\iexplore.exe" "D:\shmry-edge-computing\admin-dashboard.html"`
3. **Name**: `SHMRY Admin Dashboard`
4. **Icon**: Use IE icon or custom icon

## 🚨 **Emergency Procedures**

### **🚨 Critical Storage (80%+)**
1. **Open dashboard** immediately
2. **Click Emergency Cleanup** button
3. **Monitor progress** in real-time
4. **Check storage** after completion

### **🌐 Admin Device Issues**
1. **Test admin devices** using dashboard button
2. **Check network** connectivity

### **📥 Download Problems**
1. **Check active downloads** count

4. **Force admin redirects** if needed

## 🔧 **Troubleshooting**

### **❌ Dashboard Won't Open**
- **Check file path** - ensure `admin-dashboard.html` exists
- **Try different browser** - Chrome, Firefox, Edge
- **Run as administrator** - if permission issues
- **Check file permissions** - ensure readable

### **❌ Shortcuts Not Working**
- **Run shortcut creator** as administrator
- **Check target path** - ensure correct file location
- **Verify browser path** - ensure browser exists
- **Create manual shortcut** - if automated fails

### **❌ Dashboard Not Loading**
- **Check internet connection** - for external resources
- **Clear browser cache** - if loading issues
- **Try incognito mode** - to bypass extensions
- **Check console errors** - for JavaScript issues
