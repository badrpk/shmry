Device Setup

Installation Steps

1

Download Shmry Agent

Download the appropriate agent for your operating system:

# Windows (PowerShell)
Invoke-WebRequest -Uri "https://agent.shmry.com/windows" -OutFile "shmry-agent.exe"

# macOS/Linux
curl -O https://agent.shmry.com/linux
chmod +x shmry-agent
2

Install and Configure

Run the agent and configure it with your device settings:

# Windows
.\shmry-agent.exe --config

# macOS/Linux
./shmry-agent --config
3

Start Earning

Your device will automatically start contributing to the network and earning revenue!
