Install the ecosystem

Linux, macOS, WSL, ChromeOS Linux and Termux:

curl -fsSL https://raw.githubusercontent.com/badrpk/shmry/main/install.sh | bash

Windows PowerShell:

irm https://raw.githubusercontent.com/badrpk/shmry/main/install.ps1 | iex
The downloader detects available product installers and does not claim a native build is verified on an operating system until that product has actually been tested there.
