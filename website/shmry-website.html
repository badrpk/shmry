Get Started in 5 Minutes

1. Install & Authenticate

Terminal 
# Install
pip install shmry

# Authenticate
export SHMRY_API_KEY=sk_live_or_test_...

2. Your First AI App

Python 
from shmry import Client
c = Client()

# 1) Create a vector index
idx = c.vectors.create(name="products", dim=1536)

# 2) Upsert embeddings
idx.upsert([{"id":"p1","vector":[...],"metadata":{"title":"T-shirt"}}])

# 3) Query + generate
hits = idx.query(vector=[...], top_k=5)
print(c.ai.generate(model="shmry-large", prompt=f"Summarize {hits}"))

3. Deploy & Scale

JavaScript 
import { ShmryClient } from 'shmry';

const client = new ShmryClient();

// Deploy function
const fn = await client.functions.deploy({
  name: 'my-ai-function',
  code: async (req) => {
    const result = await client.ai.inference(req.prompt);
    return { response: result };
  }
});

console.log('Function deployed:', fn.url);
