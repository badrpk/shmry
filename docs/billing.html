Billing & Usage

Understand how Shmry bills for your usage across all services. We provide transparent pricing with clear quotas, overage rates, and tools to monitor and optimize your costs.

💰 Transparent Pricing

All pricing is upfront with no hidden fees. You only pay for what you use beyond your plan's included quotas.

Overview

Shmry uses a usage-based billing model where you pay for actual consumption of resources. Each plan includes monthly quotas for various services, and you're charged for usage beyond those limits at transparent overage rates.

Billing Cycle

Billing occurs monthly on the same date you signed up. Usage is tracked in real-time and billed at the end of each cycle.

  • Billing Date: Monthly on your signup date
  • Payment Methods: Credit card, ACH, wire transfer (Enterprise)
  • Invoicing: Automatic monthly invoices
  • Payment Terms: Net 15 for all plans

Usage Metrics

Shmry tracks usage across four primary dimensions:

Service Unit Description Included in Plans
AI Inference Token Input + output tokens processed by AI models 5K - 2M+ per month
Vector Operations Operation Vector insert, update, delete, or search 1M - 100M+ per month
Storage GB Data stored across all services 5GB - 1TB+ per month
Bandwidth GB Data transferred in/out of Shmry 100GB - 10TB+ per month

AI Inference

AI inference is billed per token (input + output) processed by our language models.

Example: Chat Completion

If you send a prompt with 50 tokens and receive a response with 100 tokens, you're charged for 150 tokens total.

Plan Included Tokens Overage Rate Example Cost
Free 5,000/month $0.002/1K tokens 100K tokens = $0.19
Builder 100,000/month $0.001/1K tokens 500K tokens = $0.40
Scale 2,000,000/month $0.0008/1K tokens 5M tokens = $2.40
Enterprise Custom Negotiated Volume discounts

Vector Operations

Vector operations include all CRUD operations on vector databases: insert, update, delete, and search queries.

Example: Product Search

Searching for similar products with a query vector counts as 1 operation, regardless of how many results are returned.

Plan Included Operations Overage Rate Example Cost
Free 1,000,000/month $0.0001/1K ops 5M ops = $0.40
Builder 10,000,000/month $0.00008/1K ops 25M ops = $1.20
Scale 100,000,000/month $0.00006/1K ops 200M ops = $6.00
Enterprise Custom Negotiated Volume discounts

Storage

Storage is billed based on the total amount of data stored across all services: vector databases, object storage, and any other persistent data.

Plan Included Storage Overage Rate Example Cost
Free 5 GB/month $0.05/GB/month 20 GB = $0.75
Builder 100 GB/month $0.04/GB/month 500 GB = $16.00
Scale 1 TB/month $0.03/GB/month 5 TB = $120.00
Enterprise Custom Negotiated Volume discounts

Bandwidth

Bandwidth includes all data transferred in and out of Shmry: API requests, file uploads/downloads, and data synchronization.

⚠️ Bandwidth Note

Data transferred between Shmry services (e.g., AI inference to vector storage) does not count toward bandwidth charges.

Plan Included Bandwidth Overage Rate Example Cost
Free 100 GB/month $0.08/GB 500 GB = $32.00
Builder 1 TB/month $0.06/GB 5 TB = $240.00
Scale 10 TB/month $0.04/GB 25 TB = $600.00
Enterprise Custom Negotiated Volume discounts

Overage & Limits

When you exceed your plan's included quotas, you're automatically charged at the overage rates. There are no hard limits that stop your service.

🔄 Automatic Scaling

Your applications continue running even when you exceed quotas. We'll bill you for the overage at the end of the month.

Soft vs. Hard Limits

  • Soft Limits: AI inference, vector operations, storage, bandwidth
  • Hard Limits: API rate limits, concurrent connections, collection count

Cost Optimization

Here are strategies to optimize your Shmry costs:

AI Inference Optimization

  • Use shorter, more specific prompts
  • Set appropriate max_tokens limits
  • Cache common responses
  • Use streaming for long responses

Vector Operations Optimization

  • Batch vector operations (100-1000 per request)
  • Use metadata filtering to reduce search scope
  • Implement vector deduplication
  • Archive old vectors to cold storage

Storage Optimization

  • Compress data before storage
  • Use lifecycle policies for old data
  • Implement data archiving strategies
  • Monitor and clean up unused resources

Billing API

Monitor your usage and billing programmatically using our Billing API:

GET /v1/billing/usage

Get current month's usage across all services.

curl -X GET "https://api.shmry.com/v1/billing/usage" \
  -H "Authorization: Bearer $SHMRY_API_KEY"
GET /v1/billing/invoices

List all invoices for your account.

curl -X GET "https://api.shmry.com/v1/billing/invoices" \
  -H "Authorization: Bearer $SHMRY_API_KEY"
GET /v1/billing/forecast

Get projected costs for the current month.

curl -X GET "https://api.shmry.com/v1/billing/forecast" \
  -H "Authorization: Bearer $SHMRY_API_KEY"
