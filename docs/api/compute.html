🚀 Compute API

Harness the power of distributed computing with SHMRY's Compute API. Deploy containers, manage edge nodes, and scale your applications globally.

Overview

The Compute API provides comprehensive control over SHMRY's edge computing infrastructure, enabling you to:

  • Deploy and manage containers across edge nodes
  • Monitor resource usage and performance
  • Scale applications automatically based on demand
  • Manage edge node clusters and load balancing
  • Deploy serverless functions and microservices

Authentication

All Compute API endpoints require authentication. Include your API key in the request headers:

Authorization: Bearer YOUR_API_KEY

Endpoints

GET
/api/compute/nodes

Retrieve all available edge computing nodes

Response

{ "nodes": [ { "id": "node-001", "name": "US-East-1", "location": "New York", "status": "active", "cpu_cores": 8, "memory_gb": 32, "storage_gb": 500, "load_percentage": 45 } ] }
POST
/api/compute/deploy

Deploy a new container or application

Request Body

{ "name": "my-app", "image": "nginx:latest", "node_id": "node-001", "resources": { "cpu_cores": 2, "memory_gb": 4, "storage_gb": 20 }, "ports": [80, 443], "environment": { "NODE_ENV": "production" } }

Response

{ "deployment_id": "deploy-123", "status": "deploying", "node_id": "node-001", "estimated_completion": "2024-01-15T10:30:00Z" }
GET
/api/compute/deployments

List all active deployments

Query Parameters

Parameter Type Required Description
status string No Filter by deployment status (active, stopped, failed)
node_id string No Filter by specific node
limit integer No Maximum number of results (default: 100)
PUT
/api/compute/deployments/{deployment_id}/scale

Scale a deployment up or down

Request Body

{ "replicas": 3, "resources": { "cpu_cores": 4, "memory_gb": 8 } }
DELETE
/api/compute/deployments/{deployment_id}

Stop and remove a deployment

Status Codes

Status Description
200 Success
400 Bad Request - Invalid parameters
401 Unauthorized - Invalid API key
500 Internal Server Error

Rate Limits

Compute API endpoints have the following rate limits:

  • Read operations: 1000 requests per minute
  • Write operations: 100 requests per minute
  • Deployment operations: 50 requests per minute

Examples

Deploy a Web Application

curl -X POST https://api.shmry.com/api/compute/deploy \ -H "Authorization: Bearer YOUR_API_KEY" \ -H "Content-Type: application/json" \ -d '{ "name": "web-app", "image": "nginx:latest", "node_id": "node-001", "resources": { "cpu_cores": 2, "memory_gb": 4, "storage_gb": 20 }, "ports": [80, 443] }'

Monitor Node Performance

curl -X GET https://api.shmry.com/api/compute/nodes \ -H "Authorization: Bearer YOUR_API_KEY"
