💾 Storage API

Store, manage, and retrieve data with SHMRY's Storage API. From simple file storage to complex data management, we've got you covered.

Overview

The Storage API provides comprehensive data storage and management capabilities, including:

  • File upload, download, and management
  • Object storage with metadata support
  • Database storage and querying
  • Data backup and versioning
  • Access control and permissions
  • CDN integration for global delivery

Authentication

All Storage API endpoints require authentication. Include your API key in the request headers:

Authorization: Bearer YOUR_API_KEY

Endpoints

POST
/api/storage/upload

Upload a file to SHMRY storage

Request Body (multipart/form-data)

file: [binary file data] bucket: "my-bucket" path: "/documents/report.pdf" metadata: { "content_type": "application/pdf", "tags": ["document", "report"], "expires_at": "2025-12-31T23:59:59Z" }

Response

{ "file_id": "file_123456", "url": "https://storage.shmry.com/my-bucket/documents/report.pdf", "size_bytes": 1048576, "uploaded_at": "2024-01-15T10:30:00Z", "checksum": "sha256:abc123..." }
GET
/api/storage/files

List files in a storage bucket

Query Parameters

Parameter Type Required Description
bucket string Yes Storage bucket name
path string No Path prefix to filter files
limit integer No Maximum number of results (default: 100)
offset integer No Number of results to skip
GET
/api/storage/download/{file_id}

Download a file from storage

Response

Returns the file as a binary stream with appropriate headers.

PUT
/api/storage/files/{file_id}/metadata

Update file metadata

Request Body

{ "tags": ["updated", "document"], "expires_at": "2026-12-31T23:59:59Z", "custom_fields": { "department": "engineering", "priority": "high" } }
DELETE
/api/storage/files/{file_id}

Delete a file from storage

POST
/api/storage/buckets

Create a new storage bucket

Request Body

{ "name": "my-project-bucket", "region": "us-east-1", "versioning": true, "encryption": "AES256", "access_control": "private" }
GET
/api/storage/buckets

List all storage buckets

Storage Classes

SHMRY offers different storage classes optimized for various use cases:

Class Use Case Availability Cost
Standard Frequently accessed data 99.99% Base rate
Infrequent Access Less frequently accessed data 99.9% 40% less
Archive Long-term backup and archival 99.9% 70% less
Edge Global content delivery 99.99% +20%

Status Codes

Status Description
200 Success
400 Bad Request - Invalid parameters
401 Unauthorized - Invalid API key
500 Internal Server Error

Rate Limits

Storage API endpoints have the following rate limits:

  • Read operations: 2000 requests per minute
  • Write operations: 500 requests per minute
  • Upload operations: 100 requests per minute
  • Download operations: 1000 requests per minute

Examples

Upload a File

curl -X POST https://api.shmry.com/api/storage/upload \ -H "Authorization: Bearer YOUR_API_KEY" \ -F "file=@document.pdf" \ -F "bucket=my-bucket" \ -F "path=/documents/report.pdf" \ -F "metadata={\"content_type\":\"application/pdf\",\"tags\":\"document,report\"}"

List Files in Bucket

curl -X GET "https://api.shmry.com/api/storage/files?bucket=my-bucket&limit=50" \ -H "Authorization: Bearer YOUR_API_KEY"

Download a File

curl -X GET https://api.shmry.com/api/storage/download/file_123456 \ -H "Authorization: Bearer YOUR_API_KEY" \ -o downloaded_file.pdf
