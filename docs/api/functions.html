⚡ Functions API

Build and deploy serverless functions with SHMRY's Functions API. Execute code on-demand without managing infrastructure.

Overview

The Functions API enables you to create, deploy, and manage serverless functions that can:

  • Process HTTP requests and webhooks
  • Handle scheduled tasks and cron jobs
  • Process queue messages and events
  • Integrate with other SHMRY services
  • Scale automatically based on demand
  • Execute in multiple programming languages

Authentication

All Functions API endpoints require authentication. Include your API key in the request headers:

Authorization: Bearer YOUR_API_KEY

Supported Languages

SHMRY Functions supports the following programming languages:

  • JavaScript/Node.js - Full Node.js runtime with npm packages
  • Python - Python 3.9+ with pip packages
  • Go - Go 1.19+ with Go modules
  • Rust - Rust with Cargo dependencies
  • PHP - PHP 8.0+ with Composer
  • Java - Java 11+ with Maven/Gradle

Endpoints

POST
/api/functions

Create a new serverless function

Request Body

{ "name": "process-data", "runtime": "nodejs18", "handler": "index.handler", "code": "exports.handler = async (event) => { return { statusCode: 200, body: 'Hello World' }; }", "memory": 512, "timeout": 30, "environment": { "NODE_ENV": "production", "API_KEY": "secret_key" }, "triggers": [ { "type": "http", "path": "/process-data" } ] }

Response

{ "function_id": "func_123456", "name": "process-data", "status": "deploying", "url": "https://api.shmry.com/functions/process-data", "created_at": "2024-01-15T10:30:00Z" }
GET
/api/functions

List all functions

Query Parameters

Parameter Type Required Description
status string No Filter by function status (active, inactive, deploying)
runtime string No Filter by runtime (nodejs18, python39, go119, etc.)
limit integer No Maximum number of results (default: 100)
GET
/api/functions/{function_id}

Get function details

PUT
/api/functions/{function_id}

Update function configuration

DELETE
/api/functions/{function_id}

Delete a function

POST
/api/functions/{function_id}/invoke

Invoke a function synchronously

Request Body

{ "payload": { "data": "Hello from API", "timestamp": "2024-01-15T10:30:00Z" }, "context": { "request_id": "req_123", "user_id": "user_456" } }
POST
/api/functions/{function_id}/logs

Get function execution logs

Query Parameters

Parameter Type Required Description
start_time string No ISO timestamp for start of log range
end_time string No ISO timestamp for end of log range
limit integer No Maximum number of log entries (default: 100)

Function Triggers

Functions can be triggered by various events:

Trigger Type Description Configuration
HTTP Web requests and webhooks Path, method, authentication
Schedule Cron-based execution Cron expression, timezone
Queue Message queue processing Queue name, batch size
Event Custom event triggers Event type, filters

Status Codes

Status Description
200 Success
400 Bad Request - Invalid parameters
401 Unauthorized - Invalid API key
500 Internal Server Error

Rate Limits

Functions API endpoints have the following rate limits:

  • Function creation: 50 requests per minute
  • Function invocation: 1000 requests per minute
  • Function management: 200 requests per minute
  • Log retrieval: 500 requests per minute

Examples

Create a Simple HTTP Function

curl -X POST https://api.shmry.com/api/functions \ -H "Authorization: Bearer YOUR_API_KEY" \ -H "Content-Type: application/json" \ -d '{ "name": "hello-world", "runtime": "nodejs18", "handler": "index.handler", "code": "exports.handler = async (event) => { return { statusCode: 200, body: JSON.stringify({ message: \"Hello World!\" }) }; }", "memory": 256, "timeout": 10, "triggers": [{"type": "http", "path": "/hello"}] }'

Invoke a Function

curl -X POST https://api.shmry.com/api/functions/func_123456/invoke \ -H "Authorization: Bearer YOUR_API_KEY" \ -H "Content-Type: application/json" \ -d '{"payload": {"name": "John"}, "context": {"request_id": "req_123"}}'

Get Function Logs

curl -X GET "https://api.shmry.com/api/functions/func_123456/logs?limit=50" \ -H "Authorization: Bearer YOUR_API_KEY"
