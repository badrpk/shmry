AI Inference API

Generate text, create embeddings, and produce images with Shmry's enterprise-grade AI models. Built for production workloads with sub-second latency and 99.9% uptime.

🚀 Production Ready

All endpoints are production-ready with automatic scaling, load balancing, and edge caching across our global network.

Overview

The AI Inference API provides access to state-of-the-art language models, embedding models, and image generation capabilities. All models are optimized for edge computing and can be deployed globally for minimal latency.

Authentication

All API requests require authentication using your API key in the Authorization header:

Authorization: Bearer sk_live_...

You can also pass the API key as a query parameter (not recommended for production):

https://api.shmry.com/v1/chat/completions?api_key=sk_live_...

Available Models

Shmry offers a range of models optimized for different use cases:

GET /v1/models

List all available models and their capabilities.

curl -X GET "https://api.shmry.com/v1/models" \
  -H "Authorization: Bearer $SHMRY_API_KEY"

Text Generation

Generate human-like text using our chat completion endpoint:

POST /v1/chat/completions

Generate text completions using chat-based models.

curl -X POST "https://api.shmry.com/v1/chat/completions" \
  -H "Authorization: Bearer $SHMRY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "shmry-large",
    "messages": [
      {"role": "user", "content": "Explain quantum computing in simple terms"}
    ],
    "max_tokens": 500,
    "temperature": 0.7
  }'

Parameters

Parameter Type Required Description
model string Yes Model ID (e.g., "shmry-large", "shmry-fast")
messages array Yes Array of message objects with role and content
max_tokens integer No Maximum tokens to generate (default: 1000)
temperature number No Creativity level 0.0-2.0 (default: 1.0)

Embeddings

Convert text to vector embeddings for semantic search and similarity:

POST /v1/embeddings

Generate embeddings for text input.

curl -X POST "https://api.shmry.com/v1/embeddings" \
  -H "Authorization: Bearer $SHMRY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "shmry-embedding",
    "input": "Your text here"
  }'

Image Generation

Generate high-quality images from text descriptions:

POST /v1/images/generations

Generate images from text prompts.

curl -X POST "https://api.shmry.com/v1/images/generations" \
  -H "Authorization: Bearer $SHMRY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "A futuristic city skyline at sunset",
    "n": 1,
    "size": "1024x1024"
  }'

Rate Limits

Rate limits are applied per API key and vary by plan:

Plan Requests/min Tokens/min Concurrent
Free 60 10,000 5
Builder 300 100,000 25
Scale 1,200 500,000 100
Enterprise Custom Custom Custom

Error Codes

Common HTTP status codes and their meanings:

Code Error Description
400 Bad Request Invalid parameters or malformed request
401 Unauthorized Invalid or missing API key
429 Rate Limited Too many requests, try again later
500 Internal Error Server error, contact support

💡 Pro Tip

Use exponential backoff when hitting rate limits. Start with a 1-second delay and double it on each retry.
