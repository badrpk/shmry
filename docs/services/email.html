Getting Started

1. Choose Your Plan

Select the plan that best fits your organization's needs. You can always upgrade or downgrade later.

2. Domain Setup

Configure your domain's DNS records to point to SHMRY's email servers:

# MX Records yourcompany.com. IN MX 10 mail.shmry.com. yourcompany.com. IN MX 20 backup.shmry.com. # SPF Record yourcompany.com. IN TXT "v=spf1 include:shmry.com ~all" # DKIM Record mail._domainkey.yourcompany.com. IN TXT "v=DKIM1; k=rsa; p=MIGfMA0GCSqGSIb3DQEBAQUAA4GNADCBiQKBgQC..."

3. Create Email Accounts

Set up email accounts for your team members through the admin dashboard:

# Create user via API curl -X POST https://api.shmry.com/api/email/users \ -H "Authorization: Bearer YOUR_API_KEY" \ -H "Content-Type: application/json" \ -d '{ "username": "john.doe", "email": "john.doe@yourcompany.com", "full_name": "John Doe", "password": "secure_password_123", "quota_gb": 25 }'

4. Configure Email Clients

Set up email clients with these server settings:

# IMAP Settings Server: imap.shmry.com Port: 993 (SSL) or 143 (STARTTLS) Security: SSL/TLS # SMTP Settings Server: smtp.shmry.com Port: 587 (STARTTLS) or 465 (SSL) Security: STARTTLS or SSL/TLS

API Reference

User Management

# List all users GET /api/email/users # Create user POST /api/email/users # Update user PUT /api/email/users/{user_id} # Delete user DELETE /api/email/users/{user_id} # Reset password POST /api/email/users/{user_id}/reset-password

Domain Management

# List domains GET /api/email/domains # Add domain POST /api/email/domains # Verify domain POST /api/email/domains/{domain_id}/verify # Remove domain DELETE /api/email/domains/{domain_id}

Email Operations

# Send email POST /api/email/send # Get email logs GET /api/email/logs # Set email rules POST /api/email/rules # Get email statistics GET /api/email/stats

Best Practices

Security

  • Use strong, unique passwords for each email account
  • Enable two-factor authentication where available
  • Regularly review and update email access permissions
  • Monitor email logs for suspicious activity
  • Implement email retention policies

Performance

  • Use appropriate storage quotas based on user needs
  • Implement email archiving for long-term storage
  • Regularly clean up old emails and attachments
  • Use email rules to organize and filter messages

Compliance

  • Document email retention and deletion policies
  • Train users on proper email usage and security
  • Regularly audit email access and permissions
  • Ensure compliance with industry regulations
