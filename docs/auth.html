Authentication

Shmry provides multiple secure authentication methods to fit your workflow. Choose from OAuth providers, phone verification, or email magic links.

🔐 Multiple Sign-in Methods: Link multiple accounts to a single Shmry user profile for seamless access across platforms.

Authentication Methods

Shmry supports the following authentication methods, all designed with security and user experience in mind:

🔑Google OAuth

Sign in with your Google account for quick, secure access. Perfect for teams already using Google Workspace.

Features

  • One-click sign-in with Google account
  • Automatic profile information sync
  • Enterprise SSO support
  • Secure token-based authentication

Setup

# Redirect users to Google OAuth
GET /auth/google

# Handle OAuth callback
GET /auth/google/callback?code=...

# Exchange code for access token
POST /auth/google/token
{
  "code": "authorization_code",
  "redirect_uri": "https://your-app.com/callback"
}

🐙GitHub OAuth

Connect your GitHub account for developer-focused authentication. Ideal for open source projects and development teams.

Features

  • Developer-friendly authentication
  • Repository access management
  • GitHub organization support
  • Code deployment integration

Setup

# Redirect to GitHub OAuth
GET /auth/github

# Handle OAuth callback
GET /auth/github/callback?code=...

# Exchange code for access token
POST /auth/github/token
{
  "code": "authorization_code",
  "state": "random_state_string"
}

📱WhatsApp OTP

Verify your phone number using WhatsApp for secure, SMS-free authentication. Works globally with any WhatsApp-enabled phone.

Features

  • No SMS costs or delays
  • Global WhatsApp coverage
  • 6-digit OTP verification
  • Rate limiting and security

Setup

# Send OTP to WhatsApp
POST /auth/whatsapp/send-otp
{
  "phone": "+1234567890",
  "country_code": "US"
}

# Verify OTP
POST /auth/whatsapp/verify-otp
{
  "phone": "+1234567890",
  "otp": "123456"
}

📧Email Magic Link

Receive a secure login link via email. No passwords to remember, just click the link to sign in instantly.

Features

  • Passwordless authentication
  • Secure, time-limited links
  • Works with any email provider
  • No app installation required

Setup

# Send magic link
POST /auth/email/send-magic-link
{
  "email": "user@example.com"
}

# Verify magic link
GET /auth/email/verify?token=magic_token_here

Account Linking

Link multiple authentication methods to a single Shmry account for flexible access and enhanced security.

# Link a new authentication method
POST /auth/link-account
{
  "provider": "github",
  "provider_user_id": "github_user_id",
  "access_token": "github_access_token"
}

# Unlink an authentication method
DELETE /auth/unlink-account
{
  "provider": "google",
  "provider_user_id": "google_user_id"
}

API Key Management

Generate and manage API keys for programmatic access to Shmry services.

⚠️ Security Note: Keep your API keys secure and never commit them to version control. Use environment variables or secure secret management.

Create API Key

# Create a new API key
POST /auth/api-keys
{
  "name": "Production API Key",
  "permissions": ["ai:read", "vectors:write", "compute:read"],
  "expires_at": "2025-12-31T23:59:59Z"
}

# Response
{
  "id": "key_abc123",
  "name": "Production API Key",
  "key": "sk_live_abc123...",
  "permissions": ["ai:read", "vectors:write", "compute:read"],
  "created_at": "2025-01-15T10:00:00Z",
  "expires_at": "2025-12-31T23:59:59Z"
}

Using API Keys

# Python SDK
import os
from shmry import Client

# Set API key in environment
os.environ['SHMRY_API_KEY'] = 'sk_live_your_api_key_here'

# Or pass directly to client
client = Client(api_key='sk_live_your_api_key_here')

# JavaScript SDK
import { ShmryClient } from 'shmry';

const client = new ShmryClient({
  apiKey: 'sk_live_your_api_key_here'
});

Session Management

Manage user sessions and implement secure logout across all devices.

# Get current session info
GET /auth/session

# Response
{
  "user_id": "user_abc123",
  "email": "user@example.com",
  "linked_accounts": ["google", "github"],
  "created_at": "2025-01-15T10:00:00Z",
  "last_active": "2025-01-15T15:30:00Z"
}

# Logout from current session
POST /auth/logout

# Logout from all devices
POST /auth/logout-all

Security Features

🔒 JWT Tokens

Secure, stateless authentication using JSON Web Tokens with configurable expiration.

🛡️ Rate Limiting

Built-in rate limiting to prevent abuse and protect against brute force attacks.

📱 Multi-Factor Support

Optional multi-factor authentication for enhanced security on sensitive operations.

🔍 Audit Logging

Comprehensive audit trails for all authentication events and API access.

🌐 CORS Protection

Cross-origin resource sharing protection for web applications.

🔐 Secure Headers

Security headers including HSTS, CSP, and X-Frame-Options for web security.

Best Practices

  • Use HTTPS: Always use HTTPS in production for secure communication
  • Store API Keys Securely: Use environment variables or secure secret management
  • Implement Rate Limiting: Add rate limiting to your applications
  • Regular Key Rotation: Rotate API keys periodically for security
  • Monitor Access: Use audit logs to monitor authentication events
  • Error Handling: Implement proper error handling for authentication failures
