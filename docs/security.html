Authentication & Authorization

API Key Management

Secure API keys with automatic rotation and granular permissions:

// Generate a new API key curl -X POST https://api.shmry.com/api/auth/keys \ -H "Authorization: Bearer YOUR_MASTER_KEY" \ -H "Content-Type: application/json" \ -d '{ "name": "production-api-key", "permissions": ["read:storage", "write:storage"], "expires_at": "2025-12-31T23:59:59Z" }'

Role-Based Access Control (RBAC)

Predefined roles with customizable permissions:

  • Admin: Full platform access and management
  • Developer: Application development and deployment
  • Operator: Monitoring and operational tasks
  • Viewer: Read-only access to resources

Multi-Factor Authentication (MFA)

Enhanced security with TOTP-based authentication:

// Enable MFA for your account curl -X POST https://api.shmry.com/api/auth/mfa/enable \ -H "Authorization: Bearer YOUR_API_KEY" \ -H "Content-Type: application/json" \ -d '{ "method": "totp", "backup_codes": true }'

Data Protection

Encryption

Multiple layers of encryption to protect your data:

  • Data at Rest: AES-256 encryption for all stored data
  • Data in Transit: TLS 1.3 for all network communications
  • Data in Use: Memory encryption for sensitive operations

Data Residency

Control where your data is stored and processed:

// Set data residency preferences curl -X PUT https://api.shmry.com/api/account/data-residency \ -H "Authorization: Bearer YOUR_API_KEY" \ -H "Content-Type: application/json" \ -d '{ "storage_region": "us-east-1", "processing_region": "us-east-1", "backup_region": "us-west-2" }'

Network Segmentation

Isolated network environments for different security levels:

Security Best Practices

For Developers

  • Never hardcode API keys in source code
  • Use environment variables for sensitive configuration
  • Implement proper input validation and sanitization
  • Follow the principle of least privilege
  • Regularly update dependencies and libraries

For Administrators

  • Enable MFA for all user accounts
  • Regularly rotate API keys and credentials
  • Monitor access logs for suspicious activity
  • Implement network segmentation
  • Regular security training for team members

For End Users

  • Use strong, unique passwords
  • Enable MFA on your account
  • Be cautious of phishing attempts
  • Report suspicious activity immediately
  • Keep your contact information updated
